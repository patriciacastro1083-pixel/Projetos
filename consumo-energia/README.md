# 📝 Primeiro Projeto: Calculadora de Consumo Elétrico Inteligente
💡
 Este projeto foi criado para praticar o ciclo **Entrada -- Processamento -- Saída**  
**Raciocinio Lógico**

Linguagem usada: Python 

Fórmulas utilizadas para os cálculos:

consumo_mensal = (potência * horas_dias * 30) /1000
consumo_por_hora = (potência / 1000)

 Como executar o programa:

O programa solicita o nome do eletrodoméstico, a potência e tempo em horas de uso por dia. Finaliza mostrando o consumo estimado em kWh/mês e o custo estimado do consumo em reais por kWh.
